# 猫鼠大战微信小游戏雏形

这是根据《猫鼠大逃杀·微信小游戏开发文档 v1.0》实现的第一版原生微信小游戏雏形。项目根目录可直接导入微信开发者工具，当前用 Canvas 程序化图形代替正式 AI 图片资源，方便先验证玩法、信息层级和移动端布局。

## 启动

微信开发者工具：选择“小游戏”，导入当前项目根目录。项目配置使用 `touristappid` 作为占位 AppID；发布前需要替换成你自己的微信小游戏 AppID。

开发者工具中如果提示网络域名校验，开发阶段打开“详情 → 本地设置 → 不校验合法域名、TLS 版本以及 HTTPS 证书”。正式发布时，应将服务器配置为 HTTPS，并在微信公众平台配置 request 合法域名。

服务器端仍然运行：

```bash
npm start
```

开发模式：

```bash
npm run dev
```

## 当前已实现

- 开始匹配后随机分配猫/老鼠身份，并切换对应视角和目标
- 2000×2000 世界地图，摄像机跟随玩家，屏幕显示放大后的局部小镇
- 小镇道路、十字主街、广场、树木、房屋和街区环境
- 纯触屏操作：点击地图位置自动寻路，点击房屋选择目标，点击攻击/事件/升级按钮
- 老鼠房门 Lv.1-Lv.4、炮台、捕鼠夹、电击网、治疗站、资源室经济
- 猫武器 Lv.1-Lv.4、疾风突进、铁壁护盾、致命一击、吸血、恐吓
- 中心随机事件：暴风雪、狂怒、资源雨、猫薄荷、地震
- 房门攻击、炮台反击、淘汰和基础胜负提示
- `/api/health`、`/api/rooms` 后端接口占位；小游戏端通过 `wx.request` 调用

## 资源替换

正式图片按 [猫鼠大战_美术资源清单与AI提示词.md](./猫鼠大战_美术资源清单与AI提示词.md) 生成，放入 `assets/` 后替换 `game.js` 中的程序化绘制函数，不需要改动服务端接口。
