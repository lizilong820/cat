# 猫鼠大战微信小游戏雏形

这是根据《猫鼠大逃杀·微信小游戏开发文档 v1.0》实现的第一版可玩原型。前端在本地运行，服务器只运行 API/房间状态服务。当前用 Canvas 程序化图形代替正式 AI 图片资源，方便先验证玩法、信息层级和移动端布局。

## 启动

服务器端：

```bash
npm start
```

本地前端：

```bash
npm run frontend
```

浏览器打开 `http://localhost:5173`。前端默认请求 `http://152.136.139.226:9001`，也可以在页面前注入 `window.CAT_MOUSE_API_URL` 覆盖 API 地址。

开发模式：

```bash
npm run dev
```

## 当前已实现

- 老鼠/猫阵营切换
- 10 栋房屋环形地图与房门 HP
- Canvas 俯视对局场景
- 移动端虚拟摇杆、桌面键盘 WASD/方向键
- 老鼠房门升级、炮台、捕鼠夹、治疗站、资源室经济
- 猫武器、疾风突进、铁壁护盾、致命一击升级占位
- 中心随机事件：暴风雪、狂怒、资源雨、猫薄荷、地震
- 房门攻击、炮台反击、淘汰和基础胜负提示
- `/api/health`、`/api/rooms` 后端接口占位，支持跨域请求

## 资源替换

正式图片按 [猫鼠大战_美术资源清单与AI提示词.md](./猫鼠大战_美术资源清单与AI提示词.md) 生成。后续可把 `public/assets/` 接入并替换 `public/app.js` 中的程序化绘制函数，不需要改动服务端接口。
